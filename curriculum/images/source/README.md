# Image source

The pictures in `curriculum/images/` are drawn by these Python scripts (no extra packages needed).
To change a picture, edit the function with its file name in `ui.py` (screen drawings) or
`concepts.py` (concept diagrams), then rebuild from this folder:

```bash
python ui.py
python concepts.py
```

The `.svg` files in `images/` are overwritten each time. You can also open any `.svg` in a text
editor and change its text directly.
